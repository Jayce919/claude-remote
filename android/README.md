# Claude Remote 安卓客户端

复刻 Claude 官方手机端的原生 App，后端接本机的 Claude Code。

电脑上跑一个 Node 服务驱动 Claude Code，手机通过 Tailscale 连过来。界面用 Kotlin + Jetpack Compose 写，配色、字体、图标、动效都是从官方 `claude.apk` 里逆向出来的，不是照着截图描的。

服务端在仓库的 `server/` 目录，`android/` 只放客户端。

## 怎么用

1. 电脑上启动服务：双击 `server\start.cmd`（或 `cd server && npm install && npm start`）
2. 把 `Claude-Remote.apk` 传到手机装上
3. 手机打开 Tailscale，登录同一个账号
4. 打开 App，填两样东西：

```
服务地址   https://<设备名>.<tailnet>.ts.net
访问令牌   见服务端启动日志
```

令牌在服务启动时打印，也写在服务端 `config.json` 的 `token` 字段里。

## 设计数据的来源

界面数值全部来自官方包 `claude.apk`（`com.anthropic.claude`），用 aapt2 和 REA 逆向。

| 项目 | 来源 | 位置 |
|---|---|---|
| 配色 | `resources.arsc` 的 183 个 color 资源 | `CdsColors.kt` |
| 字体 | 包内的 6 个 ttf（含可变字重轴） | `res/font/` |
| 图标 | 20 个 `cds_icon_*.xml` 矢量 | `CdsIcons.kt` |
| 动效曲线 | `res/interpolator/*.xml` | `CdsMotion.kt` |
| 尺寸阶梯 | `dimen` 资源 | `CdsDimens.kt` |

几个关键值：

| 角色 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#F9F9F7` | `#0B0B0B` |
| 文字 | `#29261B` | `#F5F4EF` |
| 强调 | `#C6613F` | `#D97757` |
| 代码块底 | `#F0EFEC` | `#0D0D0D` |

动效里的 `CdsEaseOut` 是 cubic-bezier(0.165, 0.84, 0.44, 1)，跟官方包 `res/interpolator/cds_ease_out.xml` 逐位一致。

代码块圆角 6dp、消息气泡圆角 10dp、输入框圆角 14dp，都是包里的原始值。

### 消息正文怎么渲染

用 CommonMark 解析成 AST，按块分派：

| 块类型 | 渲染方式 |
|---|---|
| 段落、标题、列表、引用 | 原生 Compose 文本 |
| 代码块 | 原生等宽文本 + 官方代码块底色 |
| 表格 | 原生网格 |
| 块级公式 | WebView + KaTeX |
| 行内公式 | 含公式的段落整段交给 KaTeX 的 auto-render，公式按基线嵌在文字里；纯文本段落仍走原生渲染 |

公式的 KaTeX 资源（含字体，1.5 MB）打在 APK 的 `assets/katex/` 下，和 PWA 用的是同一份。

**两个坑，都已经踩过：**

- `katex.min.css` 必须内联进 HTML。file:// 页面加载 `<link>` 会被 WebView 当成跨源样式表拦掉（脚本不受影响），症状是公式退化成没排版的纯文本。
- WebView 的 CSS 像素就是 dp。量出来的高度直接当 dp 用，不能再用设备密度换算一次，否则 75px 高的公式会被压成 26dp，只剩一条被裁掉的横条。
- 高度用注入的 `AndroidHeight` 接口上报，等 `document.fonts.ready` 之后再量，并用 `ResizeObserver` 跟着改。
- Compose 的 `Color.value` 是 ARGB 打包在 ULong 高位，`value.toLong() and 0xFFFFFF` 取到的永远是 0。浅色主题下黑字看着正常，深色主题里就成了黑底黑字。要转 CSS 颜色一律用 `toArgb()`。
- 深色主题还要在页面里声明 `color-scheme`，否则 WebView 的「强制深色」会把已经调好的浅色文字再反转一次。

行内公式只在段落里出现时启用：`$...$` 会被转成 `\( ... \)` 交给 auto-render，段落的粗体、斜体、代码、链接也会转成对应的 HTML，字体用放进 `assets/fonts/` 的 Anthropic Sans，中英文观感和原生段落一致。代价是这类段落是 WebView，长按选择走的是 WebView 自己的行为。

### 流式状态词

官方 App 等待时不显示通用转圈，而是轮换 `Thinking…`、`Working…`、`Sending…` 这类动词。这里沿用 Claude Code 原版那组约 70 个动词，从上到下随机轮换，每次淡入淡出；前面配一枚 Claude 星芒收缩呼吸动画，右侧接当前操作的完整说明（例如「运行命令：git status」）。

长任务里只有一张张工具卡片会看不出进展，所以执行中的工具还会在卡片上方留一行正文：「正在运行命令：npm test」「正在读取 app.ts（第 1–200 行）」。卡片完成后这行消失，只保留结果摘要。

### 展开详细度

思考过程与工具调用不再靠一个开关控制，而是三档：

| 档位 | 效果 |
|---|---|
| 详细 | 思考与工具调用默认展开，直接看到完整参数与结果 |
| 默认 | 思考收起，工具卡片点开看详情 |
| 精简 | 隐藏思考，工具只保留一行摘要，卡片不可展开 |

选择和货币一样用紧凑下拉选框，点一下在原地弹出选项，不跳二级面板。

### 会话标题

标题由服务端在一轮对话结束后调用一次轻量模型生成，要求 6–14 个字、概括主题、不复述第一句。生成失败或上游不可用时回退到首条消息的截断文本，不会卡住会话。

生成之后可以手动改：单击顶栏标题弹出重命名对话框，也可以从侧边栏每行的 `⋯` 菜单进入。改动先落在本地（`SharedPreferences` 里的标题覆盖表），界面立即生效，再尽力同步给服务端；旧服务没有对应接口时会静默跳过，下次连上就补同步。置顶同理，显式记录「取消置顶」，不会被服务端返回的旧值盖回去。

### 侧边会话栏

抽屉按 DeepSeek 的信息结构重排，配色和圆角仍沿用 Claude：底色 `surface1`，右侧 18dp 圆角，宽度占屏 84%（约 355dp）。

- **搜索**：顶部一颗 40dp 高的胶囊输入框，占位文案「搜索对话内容…」。输入时立即按标题过滤本地列表，220ms 防抖后再走服务端全文检索（标题、消息正文、工具块文本）；旧服务没有 `/api/search` 时保留本地结果，不报错。
- **时间分组**：置顶单独成组排在最前，其余按 `今天 / 昨天 / 7天内 / 更早` 分桶，组标题是灰色小字。分组用 `java.time` 按本地时区算自然日差，不受夏令时影响。
- **单行操作**：每行右侧一枚 `⋯`，点开 156dp 宽的圆角下拉菜单：重命名 / 置顶（或取消置顶）/ 多选 / 删除。删除是危险色。
- **多选**：进入后标题栏变成「已选 N 个」+ 取消 + 删除，行左侧出现 20dp 勾选框；选中行铺 12% 强调色底。列表刷新会自动剔除已消失的会话，选空了自动退出多选；返回键先退出多选，再关抽屉。
- **活跃状态点**：运行中的会话右侧是一枚 6dp 实心点，外面套 16dp 呼吸光环（1400ms 来回，透明度 10%→24%），比原来的静态小点更容易扫到。
- **底部**：分隔线上方是会话区，下方左侧是 Claude 像素小虫 Clawd + 「Claude Remote」，右侧齿轮打开完整设置页。小虫取自官方 `/images/clawd.svg`，按原始 11×4 方块重绘，六个 8bit 待机动作（原地碎步、慢呼吸、东张西望、开心跳跃、小碎步跑、经典四帧）按 10fps 循环轮播。

服务端的 `/api/rename`、`/api/pin`、`/api/search` 是本版新增的，电脑端 Node 需要空闲时重启一次 `start.cmd` 才会生效；重启前重命名、置顶靠本地覆盖表照常工作，搜索只过滤标题。

### 滚动与跟随

消息列表用 `LazyColumn(reverseLayout = true)`：索引 0 就是最底部。流式回复变长时视口天然钉在底部，不需要每个增量都调一次滚动，之前「任务运行时屏幕极快上下闪」的问题正是反复滚动加逐项 placement 动画叠出来的。

- 用户手动往上滑后暂停跟随，滑回底部（220px 以内）自动恢复
- 新用户消息、状态行出现或消失时贴底一次
- 运行中关掉 `animateItem`，避免长回复增长时的上下抖动

### 切换会话

最近打开过的 6 条会话历史按 LRU 缓存在内存里，连接成功后在后台预取最近 6 条。再切回这些会话时直接用本地内容铺满，网络刷新在后台进行，不再先闪半秒空白；刷新失败也保留缓存内容。

- 长会话的 JSON 解析放在 IO 线程，避免切换时卡住主线程
- 切会话后的 400ms 内暂停条目入场动画，长历史一次性铺开时不抖
- 从未打开过的会话显示「正在载入对话…」，加载完成后自动落到对话末尾
- 连续快速切换时，先发出的旧请求返回后会被丢弃，不会覆盖当前会话

### 用量与花费

设置页里新增「用量与花费」，数据来自 cc-switch 的 `proxy_request_logs`（Claude 与 Codex 的全部请求）。服务端 `/api/usage` 汇总当日、近 7 天、近 30 天三个窗口：请求数、输入 / 输出 / 缓存 token、折算花费，另附 14 天柱状图和近 7 天消耗最高的模型。手机上按 Claude 的卡片风格排布，默认只看最关键的几个数。

计价上游是美元。界面偏好的「费用货币」用下拉选框切到人民币，按固定汇率 1 美元 ≈ ¥7.2 换算，只影响显示，不参与计费。

> 这些接口是本版新加的，电脑端 Node 服务需要重启一次 `start.cmd` 才会生效；旧服务下用量面板会提示「服务端需重启」。

### 上下文与速度

顶栏下方一条细用量带，数据来自服务端新增的 `usage` 事件（每次 API 调用带一次增量，按 assistant 消息 id 去重）：

- 上下文占比：当前调用送进模型的 token ÷ 上下文窗口。窗口大小读 cc-switch 路由的 `supports1m`，标了 1M 按 1M 算，否则 200k
- 本对话累计 token：输入 + 输出 + 缓存读写
- 运行中的实时速度：流式文本按「中日韩 1 字 1 token、其余 3.8 字符 1 token」估算，每 0.7 秒刷新；工具执行期间没有新文本，速度会自然回落

行末附一条 2dp 进度条，占比到 90% 变红。打开历史会话时，服务端会从请求日志还原该会话的累计用量和最新一次上下文大小。

### 运行中发送

任务运行中按发送不会丢消息，而是弹出选择：

- **排队发送**：消息带「排队中」标记挂进当前流，等这一轮结束后由服务端按顺序喂给 Claude，上下文不丢
- **打断并发送**：先调 `/api/stop` 停掉当前任务，再把这条作为新一轮输入

服务端在每轮 `result` 事件里附带 `queued`，并在排队消息真正开始处理时发一条带 `userId` 的 `status`，客户端据此把气泡从「排队中」转正、重置单轮速度计数。

### 附件预览

点输入框左边的回形针会弹出「照片 / 文件」两个入口：

- 照片走系统相册选择器
- 文件走系统文件选择器，任意类型都行

选中的附件排在输入框上方，可左右滑动：图片显示缩略图，普通文件显示文件名和 `▤` 图标，右上角的 × 随时移除。缩略图不用 Coil 加载 data URI——Coil 2 不认这种 scheme，会静默失败只剩一个×；这里直接把 base64 解码成 Bitmap。

发送普通文件时，App 先把它经 `/api/upload` 存到电脑的 `uploads/` 目录，再把「已上传文件 + 电脑路径」拼进发给模型的正文；界面气泡里只显示用户写的话和文件卡片，不重复拼接路径。图片仍以 base64 图片块随消息发送。

### 输入框布局

回形针和发送按钮并排放进输入框内部两侧，与文字整体垂直居中；单行时不会把输入区顶到上面，换成多行后按钮仍守在两侧。输入区独占中间剩余宽度，占位符和正文共用同一条换行边界。回形针与发送箭头换成 Material 官方实心路径，比原来描边的加号和细箭头更饱满。

输入框下方只保留「权限」「模型」两个 chip，运行中多一个「停止」；「设置」已经收进左侧抽屉底部，不再重复出现。

### 返回手势

全面屏手势的返回按层级走：设置整页 → 会话抽屉 → 主界面，逐级关闭，不会一按就回桌面。权限、模型、用量这些底部面板由 `ModalBottomSheet` 自己处理返回键。

## 供应商跟随

App 里的模型列表不是写死的，来自服务端的 `/api/models`。这个接口实时读 cc-switch 的状态：

- 当前路由看 `~/.cc-switch/live-state.json` 的 `apps.claude.proxy_route`
- 供应商名和模型别名映射从 `~/.cc-switch/cc-switch.db` 的 `providers` 表读
- 候选模型 = 配置里的模型 + 代理日志近 7 天成功过的模型 + 兜底列表

所以你在 cc-switch 里换供应商、重启 Claude Code 之后，手机上打开设置页点一下「刷新模型列表」，就能看到新的供应商名和模型。

**注意**：服务端必须用 Node 22.5 以上启动，`node:sqlite` 才可用。`start.cmd` 会检查 PATH 里的 `node` 版本。版本不够时接口不会崩，但读不到数据库，只会返回兜底列表。

### 界面里显示的是真实模型名

没有 Claude 订阅，走的是 cc-switch 路由到第三方模型。所以界面上**永远显示实际调用的模型**，不显示 `claude-*` 槽位名：

- 服务端 `/api/models` 与 `/api/bootstrap` 增加 `modelRoutes`，内容是「槽位 → 上游真实模型 + 显示名」
- 顶栏副标题、输入框模型 chip、抽屉里的会话、设置页的模型列表，全部换算成真实名
- 设置页里每行主标题是真实模型，副标题（等宽小字）才是它对应的 claude 槽位，方便对照

服务端发请求时仍然用槽位名，因为 cc-switch 的路由表按槽位匹配。

## 字体与图标

**英文字体**直接用官方包里的 `anthropic_sans.ttf`（可变字重，580 是真实轴值）与 `anthropic_serif.ttf`，提在 `res/font/` 下。

**中文没有单独的字体文件可复刻。** 官方 APK 里 bundled 的六个字体（anthropic_sans/serif、jetbrains_mono、noto_serif）经 fontTools 检查都不含 CJK 码位，所以官方手机端的中文同样是系统字体兜底。这里保持同样行为，中文走 Android 自带的思源黑体，和官方观感一致，也不额外增加包体。

**数学公式**用 KaTeX（Computer Modern，即 LaTeX 默认字体风格）。官方包额外带了 `latinmodern-math.otf`，但 KaTeX 的排版指标与它自己的字体绑定，替换字体会让上下标和根号错位，所以没有替换——视觉上同属 Computer Modern 一族。

**图标用的是 Claude 官方原本的图形，没有改。** 图形从本机 Claude Desktop（MSIX 包 `Claude_4.4212.0.0_x64__pzs8sxrjxfjjc`）的 `assets/Square310x310Logo.scale-400.png` 里抠出来：底色采样为 clay `#D97757`，十二道星芒按亮度提取成白色透明 PNG。

- 桌面图标：`mipmap-*dpi/ic_launcher_foreground.png`（星芒占可视区 72dp 的 73.9%，与原图标里星芒占方块的比例一致），外加 `monochrome` 层支持 Android 13+ 主题图标
- 软件内：`drawable-nodpi/claude_spark.png` 由 `ui/theme/ClaudeMark.kt` 着色后使用，出现在空状态和抽屉标题

**抽屉底部的品牌小虫 Clawd** 来自官方网页资源 `https://claude.ai/images/clawd.svg`（66×52，11 列 × 4 行、每格 6×13 的方块，身体 `#D97757`、眼睛 `#141413`）。`ui/theme/Clawd.kt` 不引入位图，而是按原始方块点阵直接画在 Compose Canvas 上，因此任意放大都保持干净的马赛克边。

动画是六个 8bit 待机动作的轮播，全部按 10fps 逐帧切换（约 12.4 秒一轮）：原地碎步 → 慢呼吸 → 东张西望 → 开心跳跃 → 小碎步跑 → 经典四帧。每段都从静止姿势开始、回到静止姿势结束，段与段之间没有位移或眨眼状态的跳变，所以接缝处不会闪。单元格的左右上下边会先对齐到整设备像素再绘制，避免 32dp 下 1.39px/格的尺寸把相邻方块的公共边各削一次、在身体上切出浅色网格缝。静态场景（截图、列表缩略）可传 `animated = false` 关掉。

换图标后需要 `adb uninstall` 再装一次，启动器的图标缓存才会刷新。

## 设置

输入框下方只剩两个 chip：「权限」只管理权限模式；「模型」把模型列表和思考强度放在一起。供应商、工作目录、用量与花费、断开连接、界面偏好和关于全部收进左侧抽屉底部齿轮打开的整页设置里，不再走「设置」底部弹层再跳二级页。顶栏标题单击则是重命名，不兼作设置入口。

| 设置 | 说明 |
|---|---|
| 连接 | 供应商、上游、真实模型、工作目录；工作目录变更会新开会话 |
| 用量与花费 | 当日 / 7 日 / 30 日的请求数、token 与折算花费，另有 14 天柱状图 |
| 断开连接 | 二次确认后清除本机保存的地址与令牌，回到连接页 |
| 字体大小 | 0.85–1.45 倍滑杆，拖动实时预览，松手才应用到全局 |
| 外观 | 跟随系统 / 浅色 / 深色（会同时切换状态栏图标明暗） |
| 展开详细度 | 详细 / 默认 / 精简，控制思考过程与工具卡片的默认展开 |
| 费用货币 | 人民币 ¥ / 美元 $，只影响花费的显示与换算 |
| 显示耗时与费用 | 每轮结束后追加「用时 x 秒 · $x」 |
| 代码块自动换行 | 关掉后长行横向滚动 |

没输入内容时不会误触发送；打开抽屉、底部面板、设置页或切换会话前都会先收键盘并清掉输入框焦点，避免页面一换输入法又弹回来。

字号走 `Density.fontScale`，一处生效，正文、行高、卡片一起缩放；公式 WebView 用 `textZoom` 跟随。

## 适配的屏幕

按 6.31 英寸、2640×1216（19.54:9，约 422dp 宽、460dpi）校过字号、字重、图标与边框：正文 16sp / 行高 25sp，卡片边框 1dp，选中态强调线 1.5dp，图标按钮 40dp。模拟器验证用 `adb shell wm size 1216x2640 && adb shell wm density 460` 切到同一块屏。

## 构建

在 `android/` 目录下：

```bash
./gradlew assembleDebug          # Windows 用 gradlew.bat assembleDebug
```

需要 JDK 17 以上。Gradle 由仓库自带的 wrapper 负责，不用另外安装。

产物在 `app/build/outputs/apk/debug/app-debug.apk`。

如果工程路径含中文，`gradle.properties` 里加了 `android.overridePathCheck=true` 才能过 AGP 的路径检查。

版本组合：AGP 8.7.2、Kotlin 2.1.0、Compose BOM 2025.01.00、compileSdk 35、minSdk 26。

## 已知限制

**界面在没有真实设备的模拟器上验过。** 本机装了模拟器（AVD `claude`），用 `wm size 1216x2640` + `wm density 460` 摆成和手机同规格的屏，逐个界面对过。真机的厂商字体、手势条高度仍可能有出入。

**含行内公式的段落走 WebView。** 这类段落没有原生文本的手势选择与自动换行优化，属于取舍。

**组件级布局是推断的。** 反编译 Kotlin 需要 `jadx-headless-mcp` 的 JAR，下载被环境策略拦了。所以内边距和层级按 CDS 设计系统推断，色值、字体、图标、动效曲线是原样搬的。

**电脑不能休眠。** 后端跑在本机 Claude Code 上，电脑睡了就连不上。

**不在第一版的范围**：Projects、Artifacts 预览、语音输入、消息长按菜单、会话历史本地缓存。
