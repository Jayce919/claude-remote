Claude Remote 快速开始

用手机操作电脑上的 Claude Code

0先确认两件事

  1. 电脑上装了 Node.js 22.5 或更高（终端运行 node -v 能看到版本号）。没有就去 nodejs.org 装 LTS 版。
  2. 电脑上的 Claude Code 能正常出结果：终端运行 claude -p "hi"，能看到回复。这一步不通过，后面都不会成功——本工具只是把已有的 Claude Code 接到手机上，不负责配置上游。

如果你用的是第三方 API 或中转：只要 claude -p "hi" 能出字，这里就不需要任何额外配置。

1启动服务

Windows 双击 启动服务.cmd；macOS / Linux 在终端运行 ./start.sh。

首次启动会自动安装依赖（约 30 秒，需要联网）。之后窗口里会出现类似这样的内容：

  手机访问   http://192.168.1.5:8787/   （手机和电脑连同一个 Wi-Fi）
  访问令牌   3fK9...（一长串）

这个窗口要一直开着。关掉窗口，手机就连不上了。

2手机装客户端

手机连上和电脑同一个 Wi-Fi，用手机浏览器打开上一步显示的地址，例如 http://192.168.1.5:8787/，点页面上的 Claude-Remote.apk 下载并安装。

系统会提示「未知来源应用」，允许即可——这个安装包没有上架应用商店。

3连上

打开 App，填两样东西，点「连接」：

  • 服务地址：上一步浏览器里那个地址，http://192.168.1.5:8787
  • 访问令牌：启动窗口里「访问令牌」后面那一长串

连上之后，手机上发的每条消息都由电脑上的 Claude Code 处理，可以正常读写文件、执行命令。

连不上怎么办

  • 手机打不开那个地址：确认手机和电脑在同一个 Wi-Fi；Windows 第一次监听端口会弹防火墙提示，选「允许」。公司/学校网络常禁止设备互访，这种情况请用 Tailscale（见 README）。
  • 提示 401 / 未授权：令牌填错了。以启动窗口里的为准，改过 server/config.json 后要重启服务。
  • 发消息报「余额 / 额度」：这是上游 API 的问题，不是本工具。在电脑上跑 claude -p hi 确认。
  • 发消息报 model 相关错误：App 里选的模型你的上游不支持，换成「默认」或手填一个可用的模型名。
  • 窗口闪一下就关：多半是 Node 版本太旧或没装，按第 0 步检查。

安全提醒

这个服务能执行命令，等于把电脑的 shell 交给手机。启动后局域网内任何人都能看到这个端口，但没有令牌进不来。

  • 不要把端口映射到公网
  • 令牌不要发到群里、截图不要露出来
  • 只在家里/自己的设备上用
